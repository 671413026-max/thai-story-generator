# 📖 เว็บแอปพลิเคชันแต่งนิทานภาษาไทย (Pathumma LLM - AI for Thai)

เว็บแอปพลิเคชันแต่งนิทานสำหรับเด็กภาษาไทย พัฒนาด้วย **Python Flask** เชื่อมต่อโมเดลภาษา **Pathumma LLM** จากแพลตฟอร์ม **AI for Thai (NECTEC)**

---

## 🌟 ฟีเจอร์เด่น
1. **หน้าเว็บเรียบง่าย สีสันสดใส น่ารัก เหมาะสำหรับเด็ก** พร้อมรองรับ Responsive Design บนมือถือและแท็บเล็ต
2. **แต่งนิทานด้วยคำคีย์เวิร์ด** เพียงพิมพ์คำ เช่น `ลุงชัย น้ำตก หมูป่า` หรือกดชิปคำแนะนำ ระบบจะสร้างนิทานที่มีคำดังกล่าวอยู่ครบถ้วน
3. **จัดสัดส่วนเนื้อหาและข้อคิด** แยกการแสดงผลเนื้อเรื่องและกล่อง **"🌟 ข้อคิดจากนิทาน"** ไฮไลต์ชัดเจน
4. **แสดงสถานะระหว่างโหลดและแจ้งเตือนข้อผิดพลาด** มีสถานะ "พี่ปทุมมา AI กำลังแต่งนิทาน..." พร้อมแถบ Progress bar เวทมนตร์
5. **ความปลอดภัยระดับสูง** API Key ถูกเก็บและอ่านจากไฟล์ `.env` ในฝั่ง Backend เท่านั้น ไม่เปิดเผยหรือส่งไปที่หน้าเว็บ

## 🚀 วิธีติดตั้งและรันใช้งาน

### 1. ติดตั้ง Dependencies
```bash
python -m pip install -r requirements.txt
```

### 2. ตรวจสอบไฟล์ `.env`
เปิดไฟล์ `.env` เพื่อตรวจสอบหรือเปลี่ยน API Key:
```env
AIFORTHAI_API_KEY=XeVEa2LYDegFuEiLyA17Dk8QxuWLi771
PORT=5000
```

### 3. รันเซิร์ฟเวอร์
```bash
python app.py
```

### 4. เข้าใช้งานผ่านเบราว์เซอร์
เปิดเบราว์เซอร์แล้วไปที่:
👉 **[http://localhost:5000](http://localhost:5000)**
